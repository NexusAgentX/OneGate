Matching Rules

Patterns are first tried as regex (fullmatch), then fallback to fnmatch wildcards. Use $1 $2 ... in target to reference regex capture groups.

Type Pattern Meaning
Regex(.+)-(\d+\.\d+)Capture name and version into $1 and $2
Regexglm-(.+)Capture suffix after "glm-" into $1
Regex(.*)Match everything, capture into $1
Wildcard*Match any number of characters
Wildcard?Match exactly one character
Wildcard[seq]Match any character in seq
Wildcard[!seq]Match any character not in seq

Matching is case-sensitive. Regex patterns are tried first (fullmatch); if they fail or are invalid, fnmatch wildcard matching is used. Rules are matched in order; the first match wins. Unmatched model names are forwarded unchanged.
